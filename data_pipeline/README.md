# Data Pipeline Module

## Overview
This module contains the data ingestion and processing workflow for the Zepto capstone project.

## Files
- datapipeline.ipynb - Data extraction, transformation and loading workflow.
- books_database.db - SQLite database containing processed data.

## Key Activities
- Data extraction
- Data cleaning
- Data transformation
- Data validation
- Database loading
- SQL-based data processing
- Pipeline validation

## Technologies
- Python
- Pandas
- SQLite
- SQL
- Jupyter Notebook
