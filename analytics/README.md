# Analytics Module

## Overview
This module contains the data analysis and machine learning workflow for the Zepto capstone project.

## Files
- analytics.ipynb - Data profiling, exploratory data analysis, preprocessing and machine learning analysis.
- titanic.csv - Dataset generated from the Seaborn Titanic dataset.
- titanic_best_pipeline.joblib - Saved machine learning pipeline/model.

## Key Activities
- Dataset loading and profiling
- Missing-value analysis
- Descriptive statistics
- Exploratory data analysis
- Feature preprocessing
- Model development
- Model evaluation
- Pipeline creation and serialization

## Technologies
- Python
- Pandas
- Seaborn
- Scikit-learn
- Jupyter Notebook
